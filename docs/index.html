简介

ArdUi 是基于 ARD（Iroh）的 Windows 远程访问应用。设备用永久密钥证明身份，连接经过端到端加密，中央服务器只分配编号、协调连接，看不到你的密码和内容。

端到端加密

设备身份是永久公钥，连接直接在两台设备间加密，服务器只做协调，不转手你的数据。

设备编号，免配置

输入对方的编号和一次性密码，核对身份即可连接。不用 IP、端口、虚拟网卡，也不需要管理员权限。

被控端说了算

逐设备授权远程桌面（FRD）、RDP、文件，默认只开 FRD。支持“仅接受这一次”，随时断开。

对话与文件传输

文字、图片、文件（最大 2 GB）直接发给对方，显示速度与进度，可取消，传输时仍能聊天。

被控端审计录屏

对方使用屏幕时，在被控端本地录制（10 帧/秒），最多占用 10 GB，循环覆盖；使用 Windows 自带的 H.264 编码器。

灵动岛小组件

屏幕右下角的小胶囊：显示连接状态、新消息气泡、未读数和文件传输进度，点一下直接打开对话。

快速入门

两台电脑都装同一个应用。被控功能默认关闭，只想控制别人的话不用开。

下载并安装

到 Releases 下载最新的 ArdUi-vX.exe 并双击运行，会出现安装窗口。安装目录在 %LOCALAPPDATA%\ArdUi，设备身份和配置会在升级时保留。需要先装 .NET 8 与 .NET 10 桌面运行时。

被控端：开启“允许被控”

在要被访问的电脑上打开 ArdUi，打开“允许被控”，会得到 6 位编号，点击后显示 10 秒的首次密码。把编号和密码告诉对方。

主控端：输入编号和密码

在另一台电脑上输入编号与密码，点“连接”。双方通过电话等独立渠道核对完整的设备指纹，被控端点“接受”（或“仅接受这一次”，并可勾选开放哪些功能）。

开始使用

已授权的设备出现在列表里：点 FRD 看桌面，桌面 用 RDP，文件 访问共享，点对话图标发消息和文件。之后再连不用重新输入密码。

提示：被控端在“被控与授权”里可以随时撤销某台设备或断开正在使用的连接；有人使用屏幕时，被控端首页会在该设备旁显示“● 录屏中”。

自托管

默认使用公共的设备目录服务。想完全掌握在自己手里，可以在一台有域名的 Linux 服务器上部署自己的目录服务，一条命令完成。

一键部署目录服务

需要：Linux（systemd）、root 权限、已指向本机的域名、开放 80/443 端口。脚本会安装 Python 环境、目录服务和带自动 HTTPS 的 Caddy。

curl -fsSL https://katey07.github.io/ArdUi/selfhost.sh | sudo bash -s -- --domain ardui.example.com

先预览不改动：加 --dry-run；已有反向代理：加 --http-only；卸载：--uninstall（数据保留）。

让客户端使用它

脚本结束时会打印这一步。在每台电脑的 ArdUi 数据目录里改配置，然后重启 ArdUi：

# %LOCALAPPDATA%\ArdUi\data\config.json
{
  "server": "https://ardui.example.com/"
}

验证：浏览器打开 https://你的域名/api/health，应返回 "ok": true。

范围说明：脚本部署的是设备目录服务（编号、在线状态、连接协调）。流量中继和中继目录（M）默认仍使用公共节点；如果也想自建，请参考仓库里的 中继节点部署文档，那部分目前需要手动完成（证书与节点登记）。我们还没有在全新服务器上做完整的端到端验收，遇到问题请到 Issues 反馈。
