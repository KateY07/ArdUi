# ArdUi v5.pre1

v5 起，旧版本客户端不再允许接入；服务端同步升级为 v5.pre1。设备身份、授权、`config.json` 和服务器上的设备数据都保留，不需要重新配对。

**升级与兼容**
- 目录服务器拒绝所有低于 v5.pre1 的客户端（没有版本标识的所有旧版本、v4 及以前），返回“客户端版本过旧，请升级到 ArdUi v5.pre1 或更高版本”，ArdUi 界面会提示“需要升级 ArdUi”。
- 客户端在每个请求里带上自己的版本；连接请求（由控制方签名）里也带版本，被控端会再核对一次，过旧的控制方一律拒绝。
- 服务端健康页 `/api/health` 显示当前版本和要求的最低客户端版本（`minClient`）。
- 安装包会安装到新的 `versions\v5.pre1`，原有数据目录和配置保持不变；旧版本目录不会再被用到，可以手动删除。

**包含 v4.pre9 的全部功能**
- 首页改版：输入 6 位设备 ID 连接，连接过程在“已连接”区域以占位卡片展示，聚焦和输入时背景变暗，连接按钮随输入状态变化。
- 对话：文字、图片、文件、视频（最大 2 GB），先添加后发送，进度条、速度、取消，传输时仍可聊天。
- 被控端：按设备授权（FRD / RDP / 文件，默认只开 FRD）、“仅接受这一次”、首页显示谁在连接，审计录屏（用屏幕时录制，10 帧/秒，10 GB 循环覆盖，不可关闭；使用 Windows 自带的 H.264 编码器（Media Foundation），保存为分片 MP4，不依赖 FFmpeg）。
- 灵动岛：屏幕右下角（托盘上方）的小胶囊，可拖动（托盘图标的增强），显示已连接状态、新消息气泡（4 秒，鼠标可穿透）、未读数和文件传输进度（可取消）；点击打开对话。全屏或演示时默认不显示，可在 设置 → 通用 → 界面 中关闭或改为总是显示。
- 设置页、历史下拉、开始菜单项和图标、开机启动开关等。
- 集成 FRD v3.pre1（Native AOT，无需 .NET 运行时；默认使用 Windows 自带的 Media Foundation H.264，安装包不含 FFmpeg）。FFmpeg 为可选扩展：把 FRD 的 `v3.pre1-ffmpeg.zip` 解压到 `versions5.pre1rd\`（FRD.exe 同目录），升级 ArdUi 时安装程序会把已有的 `frdfmpeg` 带到新版本目录。
- 安装包用 onesetup v3.pre10 制作（带安装界面）。运行 ArdUi 只需 .NET 8 运行时。
