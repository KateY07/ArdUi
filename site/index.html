预发布控制台原型

ArdUi v1.pre5

通过永久设备身份与 ARD 端到端连接，访问已授权 Windows 设备的远程桌面和 SMB 文件共享。

一键安装

在普通 PowerShell 窗口执行：

irm https://f.visnova.cn/ardui/install.ps1 | iex

支持 Windows 11 24H2 / Windows Server 2025 x64 及以上。不请求管理员权限，不安装 Wintun；内置 Python 3.13、ARD 和所需依赖。

使用流程

  1. 启动后先查看被控状态；仅在开启被控时显示本机 6 位设备 ID 与 EndpointId。
  2. 选择 H 设置访问密码并开启被控。
  3. 另一端选择 A，输入 6 位设备 ID 与访问密码。
  4. 双方选择 V，通过独立渠道核对完整 EndpointId，首次连接由被控端同意。
  5. 授权设备显示在编号列表中。按数字进入设备菜单，打开远程桌面或 SMB，也可连接、断开。

身份与安全

安装脚本首次创建 %LOCALAPPDATA%\ArdUi\data\identity，修复和升级不会覆盖。EndpointId 是永久公钥指纹；访问密码只在经过身份验证的端到端连接中发送，协调服务器不接收密码或密码哈希。

首次安装仍需信任本站提供的脚本与发布包。首次设备核对请使用电话、当面等独立渠道。

当前范围

这是用于跑通流程的控制台预览版，内置 ARD 2.0.0-pre.5，并固定 ArdRelay 公钥。TCP、真实本机 SMB、多设备和强制断线重连已纳入自动回归；跨两台真实 Windows 设备的 RDP 登录仍需继续验收。
