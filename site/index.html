Avalonia 预发布版

ArdUi v1.pre10

通过永久设备身份与 ARD 端到端连接，访问已授权 Windows 设备的远程桌面和 SMB 文件共享。

一键安装

先安装 Microsoft .NET 8 Runtime x64，然后在普通 PowerShell 窗口执行：

irm https://f.visnova.cn/ardui/install.ps1 | iex

支持 Windows 11 24H2 / Windows Server 2025 x64 及以上。不请求管理员权限，不安装 Wintun。

使用流程

  1. 默认关闭被控；开启后才显示本机机器码、完整 EndpointId 和首次生成的随机密码，点击按钮可复制 ID。
  2. 被控密码直接显示，编辑后自动保存；仅在有人正在访问时显示活动设备，可一键断开。
  3. 输入对方 6 位机器码和访问密码添加设备；首次请求由被控端在主界面点击“是”或“否”。
  4. 双方通过独立渠道核对完整 EndpointId。获准后，从设备列表直接打开远程桌面或 SMB 文件共享。
  5. 活动连接显示 P2P 直连或 ArdRelay 中继、TCP/PsPing RTT 与 UDP 往返延迟。

身份与安全

安装脚本首次创建 %LOCALAPPDATA%\ArdUi\data\device\identity；修复和升级保留身份、机器编号、已授权设备、访问密码和“允许被控”设置。EndpointId 是永久公钥指纹；访问密码只在经过身份验证的端到端连接中发送，协调服务器不接收密码或密码哈希。

首次安装仍需信任本站提供的脚本与发布文件。首次设备核对请使用电话、当面等独立渠道。

当前范围

v1.pre10 是无 XAML、单 C# 核心实现的 Avalonia 图形版。安装脚本分别校验 ArdUi 与 ARD 2.0.0-pre.6，并固定 ArdRelay 公钥；RDP 本地入口同时转发 TCP 与 UDP。
