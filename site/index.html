Avalonia 预发布版

ArdUi v2.pre1

通过永久设备身份与 ARD 端到端连接，访问已授权 Windows 设备的远程桌面和 SMB 文件共享。

一键安装

先安装 Microsoft .NET 8 Runtime x64，然后在普通 PowerShell 窗口执行：

irm https://f.visnova.cn/ardui/install.ps1 | iex

支持 Windows 11 24H2 / Windows Server 2025 x64 及以上。不请求管理员权限，不安装 Wintun。

使用流程

  1. 默认关闭被控；开启后显示本机机器码；首次密码点击后显示 10 秒，EndpointId 收纳在小型折叠菜单中。
  2. 在授权列表上方输入对方机器码和首次密码；首次请求由被控端点击“是”或“否”。
  3. 双方通过独立渠道核对完整 EndpointId。获准后无需再次输入首次密码，直至被控端人工撤销。
  4. 从单行设备列表直接打开远程桌面或 SMB 文件共享；断线后自动重建 ARD 会话并保持本地转发端口。
  5. 活动连接显示路径类型、UDP 往返延迟和低频测得的预计可用带宽；网络诊断按需展开。

身份与安全

安装脚本首次创建 %LOCALAPPDATA%\ArdUi\data\device\identity；修复和升级保留身份、机器编号、已授权设备、访问密码和“允许被控”设置。EndpointId 是永久公钥指纹；访问密码只在经过身份验证的端到端连接中发送，协调服务器不接收密码或密码哈希。

首次安装仍需信任本站提供的脚本与发布文件。首次设备核对请使用电话、当面等独立渠道。

候选中继

v2.pre1 在原有直连优先路径之外，支持独立 ArdTransit 候选节点。双方都能直连该节点且实测延迟、丢包和带宽满足切换条件时，自动选择更好的路径。候选只转发端到端密文，TCP 与原生 UDP 都受支持；故障回退尽量保留原业务连接。

普通客户端无需设置候选节点，也不会自动替别人转发。自愿提供节点的用户可下载 ArdTransit 原型与运行说明；需要 Python、cryptography 和可信 ARD。客户端可在网络诊断中导出 ZIP。

已验证真实 ARD 三节点 TCP/UDP 与故障恢复；尚未据此证明不同 NAT/IPv6 网络中的性能或 Windows 远程桌面已实际协商 UDP。全部路径长时间失效、应用退出及业务自身超时仍可能中断连接。

当前范围

v2.pre1 使用 Avalonia SimpleTheme、无 XAML、单 C# 核心实现。安装脚本配置当前用户开机自启动，分别校验 ArdUi 与 ARD 2.0.0-pre.6，并固定 ArdRelay 公钥；已通过 SHA-256 的本地文件会直接复用，只下载缺失或变化的文件。升级需两端都安装 v2.pre1 才能使用新传输层，身份与已有授权保留。
