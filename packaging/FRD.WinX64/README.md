# KateY07.FRD.WinX64

This package contains the compressed FRD Windows x64 runtime supplied by the FRD development team, the archive checksum, and the checksum of every included runtime file. ArdUi integrates the delivered binary through its documented CLI and does not build or modify FRD source.

It is versioned independently so ArdUi upgrades can reuse the unchanged FRD runtime.
