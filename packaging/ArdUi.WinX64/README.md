# KateY07.ArdUi.WinX64

This package contains the Windows x64 `ArdUi.exe`, its SHA-256 checksum, the installer, default configuration, and third-party notices.

It has exact NuGet dependencies on the compatible `KateY07.Ard.WinX64` and `KateY07.FRD.WinX64` versions. NuGet can therefore reuse unchanged ARD and FRD packages when ArdUi alone is upgraded.

The application is framework-dependent. Install the .NET 8 and .NET 10 x64 runtimes before use.

ARD source code is not included.
