# ArdUi v5.2（正式版）

v5.2 是 v5 的第一个正式版（包含 v5.pre1 的全部内容）。v5 起，旧版本客户端不再允许接入。设备身份、授权、`config.json` 和服务器上的设备数据都保留，不需要重新配对。

**v5.2 相对 v5.pre1 新增**
- 语音通话、麦克风诊断页、中英文界面（设置 → 通用 → 语言）、网络诊断（M 辅助实测）、灵动岛显示通话。
- 集成 FRD v4.pre3（窗口语言跟随 ArdUi 的语言设置）。
- 被控端主动断开后，主控端不再反复重连；安装程序先结束正在运行的 ArdUi/FRD 再覆盖；安装包文件名为 `ArdUi-v5.2_setup.exe`。
- 版本号：正式版使用 `v5.2` 这样的格式；与目录服务器通信时仍以 `v5.pre2` 的形式报告，所以不需要先升级服务器，v5.pre1 的服务端可以直接接受。

**升级与兼容**
- 目录服务器拒绝所有低于 v5.pre1 的客户端（没有版本标识的所有旧版本、v4 及以前），返回“客户端版本过旧，请升级到 ArdUi v5.pre1 或更高版本”，ArdUi 界面会提示“需要升级 ArdUi”。
- 客户端在每个请求里带上自己的版本；连接请求（由控制方签名）里也带版本，被控端会再核对一次，过旧的控制方一律拒绝。
- 服务端健康页 `/api/health` 显示当前版本和要求的最低客户端版本（`minClient`）。
- 安装包会安装到新的 `versions\v5.pre1`，原有数据目录和配置保持不变；旧版本目录不会再被用到，可以手动删除。

**包含 v4.pre9 的全部功能**
- 首页改版：输入 6 位设备 ID 连接，连接过程在“已连接”区域以占位卡片展示，聚焦和输入时背景变暗，连接按钮随输入状态变化。
- 对话：文字、图片、文件、视频（最大 2 GB），先添加后发送，进度条、速度、取消，传输时仍可聊天。
- 被控端：按设备授权（FRD / RDP / 文件，默认只开 FRD）、“仅接受这一次”、首页显示谁在连接，审计录屏（用屏幕时录制，10 帧/秒，10 GB 循环覆盖，不可关闭；使用 Windows 自带的 H.264 编码器（Media Foundation），保存为分片 MP4，不依赖 FFmpeg）。
- 灵动岛：屏幕右下角（托盘上方）的小胶囊，可拖动（托盘图标的增强），显示已连接状态、新消息气泡（4 秒，鼠标可穿透）、未读数和文件传输进度（可取消）；点击打开对话。全屏或演示时默认不显示，可在 设置 → 通用 → 界面 中关闭或改为总是显示。
- 设置页、历史下拉、开始菜单项和图标、开机启动开关等。
- 集成 FRD v4.pre3（Native AOT，无需 .NET 运行时；默认使用 Windows 自带的 Media Foundation H.264，安装包不含 FFmpeg）。FFmpeg 为可选扩展：把 FRD 的 `v4.pre3-ffmpeg.zip` 解压到 `versions\v5.pre1\frd\`（FRD.exe 同目录），升级 ArdUi 时安装程序会把已有的 `frd\ffmpeg` 带到新版本目录。
- 安装包用 onesetup（带安装界面和图标） 制作（带安装界面）。运行 ArdUi 只需 .NET 8 运行时。

**中英文界面（新）**
- 界面支持中文和英文：设置 → 通用 → 语言，默认跟随 Windows 显示语言，重启后生效。对话内容和设备名不会被翻译。

**语音通话（新）**
- 在对话窗口顶部点电话按钮呼叫已连接的设备；对方窗口和灵动岛都会响铃，可接听、拒绝、静音、挂断。声音用 Opus（16 kHz、24 kbps，丢包补偿）经同一条加密链路传输（直连或中继）。
- 一方没有可用的麦克风或扬声器也能通话，双方都会看到提示（“对方麦克风不可用”“本机扬声器不可用”“对方已静音”）。
- 被控端的审计日志记录通话（时间、时长、结果），不录声音。设置 → 通用 可关闭语音通话。暂无回声消除，请戴耳机。
- 设置 → 麦克风诊断：音频设备、Windows 麦克风隐私开关、5 秒实测（帧数、音量、爆音、全静音）、录音回放、测试音。
- 网络诊断：M 辅助的实际探测（UPnP / NAT-PMP 实测映射、公网入口验证）。被控端主动断开时主控端不再重连。安装程序先结束正在运行的 ArdUi 再覆盖。
