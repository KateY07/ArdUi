# ArdUi v5.4

**灵动岛**
- 本机正在被控制（FRD 已启动或有 RDP 连接）时显示红点和“被控中”；只是连着、聊天或传文件时仍然是绿点。
- 点击：有通话、未读消息或文件传输时打开对应的对话；什么都没有时打开 ArdUi 主窗口，不再无故打开聊天。
- FRD 在被控屏幕右下角显示状态卡片时，灵动岛自动挪到卡片左边，卡片消失后回到原位。
- 远程控制者在这台电脑上移动鼠标时，灵动岛对它穿透，不会拦截它的点击；本机的人一动鼠标就恢复。

**安全**
- 确认类和权限类控件必须由被控端的人亲自操作：首次连接确认（仅接受这一次、接受并信任）、“每次被控前确认”的允许、指纹核对里的信任、修改设备权限、开启被控、关闭“每次被控前确认”、邀请设备和显示密码。FRD 控制者注入的点击和按键会被拒绝，并提示需要本机的人操作。这是防止控制者自己批准或升级权限，不是防一个已经拿到桌面的恶意者（对方仍可结束 ArdUi 或改文件）。RDP 的输入无法区分，不在此保护之内。

**修复**
- 一方主动结束连接（点“断开”、移除设备、退出 ArdUi）时，另一方不再显示“正在恢复连接”，会直接结束会话。
- 被控期间被控端鼠标指针闪烁（v5.3 已含）。

**内部（未启用）**
- WebRTC 链路的第一步：一次性会话、双向加密心跳，仅作为命令行测试（`--rtc-test`）和源码（`rtc/`、`Rtc/`），不在安装包里，也不影响现有连接。

**兼容**
- 与 v5.3 完全兼容；对目录服务器仍以 `v5.pre4` 的形式报告版本，现有服务器无需升级。
