# ArdUi v4.pre8

- 设备列表只显示状态，不再主动连接：启动后不会对任何设备发起连接或打洞。行内显示“在线 / 离线 / 状态未知”和“最近连接”时间；点“桌面 / FRD / 文件”才连接，离线设备的连接按钮置灰。用户主动打开的连接断开后，只在对方在线时自动恢复。
- 列表按最近连接时间排序（最近的在前）。新增“分组”，同组设备放在一起，组按最近使用排序。
- 显示被控端的计算机名，与自己的备注并列（备注 · 计算机名 · 编号）。需要服务器支持（见下）。
- 同一数据目录只运行一个 ArdUi：再次启动（开机自启、快捷方式、安装器）会唤起已有窗口并退出。安装器会先结束旧版本进程，再启动新版本。
- 托盘图标：点击窗口关闭或最小化只会隐藏到托盘，点击托盘图标显示，右键“退出 ArdUi”才真正退出。收到授权申请时自动显示窗口。
- 服务器（arduiserver）新增在线状态与计算机名接口：只有持有对方签名授权的设备才能查询其状态，旧版客户端不受影响。
- `config.json`、身份和授权保持不变；内置 ard.exe（4.0.0-pre.2）和 FRD v2.pre6。
