# ArdUi v5.3

**新增**
- 设置 → 被控与授权 → “每次被控前都需要人工确认”：开启后，已信任的设备每次建立新连接也要等你点“允许连接”，不点就不会被控（断网后的自动恢复不再询问）。默认关闭。
- 集成 FRD v5.1（与 v5.0、v4.pre1 及以后互通）。FFmpeg 扩展仍可解压到 `frd\ffmpeg`，v5.1 也会去 `%LOCALAPPDATA%\FRD\ffmpeg\` 找。
- 安装包用 onesetup v4.1 制作：安装完成后出现“启动 ArdUi”按钮（按 Enter 也可以），安装程序不再自己启动。

**修复**
- 被控期间被控端的鼠标指针不再闪烁：审计录屏抓屏时去掉了 `CAPTUREBLT` 标志（现代 Windows 的桌面合成已包含分层窗口，录像内容不受影响）。

**不变**
- 与 v5.2 完全兼容；对目录服务器仍以 `v5.pre3` 的形式报告版本，现有服务器无需升级。
