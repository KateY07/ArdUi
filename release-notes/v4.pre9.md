# ArdUi v4.pre9

- 界面整体改为简约风格：暖白背景、暖黑文字、单一赭红强调色，卡片用发丝细边框代替粗描边，按钮扁平圆角（主操作用强调色，其余为浅色），输入框圆角、聚焦时强调色描边，滚动条变细，状态点和按钮有短过渡动画。
- 无边框窗口：没有系统标题栏，整个顶部空白区域都可拖动（双击最大化/还原），最右上角依次是最小化和关闭（都隐藏到托盘）；所有图标统一为同一套线条样式。
- 左上角显示“ArdUi”和 6 位设备 ID，已连接可信服务器时 ID 为绿色。“允许被控”改为开关，开启后其右侧出现分享图标（邀请）。
- 设备列表为两行：备注或计算机名（加粗）、另一个名称和编号（浅色）；第二行显示在线状态和最近连接时间。状态点区分四种状态：已连接（实心深绿带光晕）、在线未连接（空心绿环）、连接中（琥珀色呼吸）、离线（灰色小点）。每台设备先点“连接”，连接成功后才出现“桌面 / FRD / 文件”和“断开”；离线设备的“连接”置灰，更多操作收进“⋯”。
- 邀请改为叠加层：开启“允许被控”后点击“邀请”，显示带圆环倒计时的首次密码（到期自动隐藏，可重新显示）、设备 ID 和完整 EndpointId（始终显示，供核对）；一个“一键复制”按钮复制全部邀请信息；有设备被授权后自动关闭。
- 已知离线的设备默认折叠在列表底部的“离线设备”中，点击展开；离线设备用紧凑的小行显示。
- 取消右侧栏，整个界面为单列：“正在访问本机”和“可访问本机的设备管理”放在设备列表下方。
- 收到授权申请时，在整个窗口中央弹出确认卡片，背景变暗并阻止其后的操作，层级高于邀请叠加层。所有叠加层的关闭按钮统一为右上角的 ✕。
- 包含 v4.pre8 的全部功能：设备列表按最近连接排序、在线状态、不主动连接、分组与计算机名、单实例、托盘。
- 集成 FRD v2.pre14。
- 设备卡片：已连接的状态行显示“路径（IPv6 / IPv4 / Relay）· 速度 · 延迟”；FRD 为主要远程入口（图标），RDP 收进“⋯”；断开为圆形 ✕ 按钮。卡片带轻微毛玻璃效果。
- 首页：有设备连接时，“连接到设备”面板压缩为顶部悬浮的一行；连接过程在“已连接”区域以占位卡片展示（进度、原位输入连接密码、失败提示、成功对勾），连接成功后只出现一行。设备历史下拉显示在线状态；复制成功显示居中的毛玻璃提示；标题栏移除最小化按钮（关闭即隐藏到托盘）。
- 被控端权限：授权确认时可选择对方可用的 FRD / RDP / 文件共享（默认只允许 FRD），并新增“仅接受这一次”（主按钮，不保存授权，断开即失效）与“接受并信任”；“被控与授权”页可随时修改每台设备的权限，修改会断开对方当前会话。升级前已授权的设备保持原有的全部权限。控制端只显示被控端允许的入口。
- 交互：输入或聚焦设备 ID 时背景变暗聚焦，悬浮连接面板轻微上浮；连接按钮在输入完整后“苏醒”并扩散光环，连接中变为转圈、输入框锁定，失败时输入框轻抖；输入前几位即提示并高亮匹配的最近设备（Tab 补全）；按钮按下有下沉反馈，历史下拉的箭头带翻转动画。设置 → 通用新增“减少动画”（也跟随系统的动画开关）。
- 设备 ID 输入框禁用输入法，只接受英文字母和数字；邀请页适配最小窗口宽度。
- 开机启动：安装程序不再默认创建开机启动项（旧版安装程序总是创建“启动”文件夹里的 ArdUi.lnk，所以即使没有勾选也会自启动）。“设置 → 通用 → 随 Windows 启动”现在同时反映并管理这两种启动方式：取消勾选会一并删除；如果已存在旧的启动快捷方式，开关会显示为已开启。
- 修复：会话进行时界面无响应。ard 以 trace 级（-vv）输出时每秒上千行，每一行都触发一次界面刷新，被控端在有设备连接时会卡死。现在日志默认记录调试级信息（-v），逐包 trace 需手动开启；状态未变化时不再通知界面，连续事件合并为一次刷新。
- 对话：连接后，会话卡片上出现对话图标（主控端和被控端都有），可以互发文字、图片和文件（单个文件最多 50 MB，图片最多 10 MB，也可以直接拖进对话窗口，或在输入框里 Ctrl+V 粘贴图片和文件；Enter 发送，Shift+Enter 换行）。走与会话相同的加密通道，不经过服务器；文件按校验值核对，保存在本机 data\chat 下；收到消息时有提示和红点。
- 被控端审计录屏：控制方在使用本机屏幕期间（FRD 在运行，或 RDP 连接打开）自动录屏（10 帧/秒，主显示器，含鼠标指针；仅连着、只传文件或聊天时不录；屏幕停用 10 秒后停止录制，再次使用时继续写入同一会话的文件夹），保存在本机 dataudit，每个会话一个文件夹（视频分段、对话记录、收发的文件）；总量上限 10 GB，超出后自动覆盖最旧的内容；不加密、不可关闭。录屏无法启动或中途停止时，该会话会被断开。被控端首页显示“● 录屏中”；“设置 → 被控与授权 → 审计记录”可查看用量和最近的会话，并打开审计文件夹。告知控制方由使用约定负责，界面不提示。
- 对话的文件、图片、视频：先添加到输入框下方（回形针、拖入或 Ctrl+V），按发送才发出；每个文件单独传输，显示进度条、速度和剩余时间，发送方和接收方都可以取消，传输时可以继续发消息和发送别的文件。单个文件最大 2 GB，传输中按链路快慢自动调整在途数据量，避免把会话自己的保活包堵住。
- 修复：发送文件时反复“正在恢复连接”。控制请求必须小于 64 KB 一帧，过大的帧会让对端丢弃整条覆盖层链路；文件块缩小到 36 KB，并在发送端对超过 60,000 字节的控制请求直接拒绝。
- 修复：设备 ID 输入框点空白处退出聚焦；邀请页适配最小窗口宽度；被控端首页显示谁在连接、权限和“录屏中”。
- 安装时在开始菜单添加“ArdUi”（直接运行程序本身，带 ArdUi 图标，而不是命令脚本），可以从开始菜单搜索或点击启动；程序文件本身也带上了图标。每次安装会把它更新为刚装的版本。
