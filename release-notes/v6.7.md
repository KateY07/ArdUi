# ArdUi v6.7

**不兼容旧版本**：v6.7 只能与 v6.7 及以上互连，服务器也拒绝 v6.7 以下的客户端。v6.3 及以上的旧版会自动下载新版并提示安装。

**账号（新）**
- 只有登录的设备可以连接（控制）其他设备；未登录的设备显示“匿名用户”，只能被控。被控的一方不需要登录。
- 账号由网络管理员创建（用户名必填）；用户可在 设置 → 通用 → 账号 中登录、修改密码、退出登录。标题栏显示当前用户名或“匿名用户”，点击即可进入账号设置。
- 服务器（M）新增管理页面 `https://你的域名/api/admin`：管理员登录后可以新建用户（初始密码可自动生成）、重置密码（会登出该用户的设备）、停用或启用用户、设为管理员、删除用户、修改自己的密码。
- 自托管：第一个管理员在服务器上创建：`sudo -u arduiserver python3 /opt/arduiserver/arduiserver.py --add-user 名字 --admin`（打印一次初始密码）。
- 发布文件可以用一次性令牌上传到服务器：`sudo -u arduiserver python3 /opt/arduiserver/arduiserver.py --upload-token`。


**v6.6 的内容（未单独发布）**

**兼容（v6.6）**：v6.6 只能与 v6.6 及以上互连，官方服务器也已拒绝 v6.6 以下的客户端（权限的含义变了：对话包含文件与通话，“文件”是共享文件夹）。v6.3 及以上的旧版会自动下载新版并提示安装；更早的版本请手动安装。

**共享文件夹（新）**
- 设备卡片上新增“文件”：在浏览器中打开对方的共享文件夹，可以浏览、下载（可续传）、上传多个文件（逐个显示进度、速度和剩余时间，可取消、重试）、新建文件夹、重命名、删除。也可以在资源管理器中打开 `\\127.0.0.1@端口\DavWWWRoot`（WebDAV）。
- 每台设备在本机的地址固定（例如 `http://127.0.0.1:43409/`），重连、重启后不变，可以存成书签。
- 只在直连时可用；经 ArdFerry 中继时不可用，传输中切到中继会断开（下载可续传），避免占用志愿节点的带宽。
- 被控端在 设置 → 被控与授权 → 共享文件夹 中选择文件夹；不选时，每台主控设备使用自己的文件夹：`文档\ArdUi 文件\<计算机名>-<设备ID>`。本机也可以“在浏览器中打开”查看。
- 删除和覆盖的内容移到共享文件夹中隐藏的 `.ardui-trash`，可以找回。
- 列表显示每个文件的上传人；上传、下载、删除、改名、新建文件夹等操作记入被控端该会话的审计记录（`files.jsonl`）。
- 不能访问共享文件夹以外的位置：`..`、目录联接和符号链接、备用数据流、设备保留名一律拒绝。

**权限调整**
- “对话”包含文字、文件与图片、语音通话；“文件”改为共享文件夹的读写权限；不再单列“通话”。
- 新授权默认包含 FRD、对话和文件。

**对话**
- 发出的消息和文件立即显示，并标明“发送中 / ✓ 已送达 / ✓✓ 已读 / 未送达（重试）”；重试沿用同一条消息，对方不会收到两条。
- 已读回执：对方看到消息后显示“已读”；可在 设置 → 通用 → 对话 中关闭“发送已读回执”。
- 对话附件可续传：连接中断后重试，从已收到的位置继续。
- 文字消息不再排在文件传输后面。
- 新增“抖一抖”：提醒对方查看对话（10 秒内一次）；对方的灵动岛会抖动，并显示“xxx 发送了抖一抖”，点击直接打开对话，不会自动消失。
- 共享文件夹网页的上传可续传：按 8 MB 分段，断开后自动重试，失败后点“重试”从已上传处继续。

**改进**
- 设备卡片上的延迟每秒更新（取会话层每 500 ms 探测的最近三次中位数，不增加流量）；连上后先显示延迟，带宽稍后补上。
- 集成 FRD v5.5：远程桌面窗口标题显示设备名（v6.4）。
