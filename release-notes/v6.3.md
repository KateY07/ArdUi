# ArdUi v6.3

**兼容**：可与 v6.2、v6.pre2 互连。官方服务器仍拒绝 v6.pre2 之前的版本（包括 v5.5、v6.pre1）。

**下载引导（新）**
- 有新版本时，ArdUi 在后台从自己的服务器（M）下载安装包，平时不打扰；下载完成后弹出提示，由你决定是否安装，不会自行安装。
- 当前版本被服务器拒绝时，会立即弹出提示并显示下载进度，下载完成后即可安装。
- 下载可断点续传；已下载并校验过的不重复下载；大小或 SHA-256 与服务器公布的不一致的文件会被删除，不会被安装。
- 失败后不会频繁重试：等待时间从 1 分钟起逐次加倍，最长 1 小时。
- 安装时 ArdUi 会关闭，当前连接会断开；需要本机的人亲自点击，远程操作不能触发安装。
- 旧版本仍保留在安装目录的 `versions\` 下。
- v6.2 及更早的版本没有这个功能，需要手动安装这一次。

**服务器（自托管）**
- M 包现在包含同一版本的 ArdUi 安装包（`client/ArdUi-v6.3_setup.exe`），`selfhost.sh` 安装时直接从 M 包中取出，提供给本网络的客户端，不需要另外从 GitHub 下载。
- 新增接口：`GET /api/v1/release`（最新版本、大小、SHA-256）和 `GET /api/v1/release/<文件名>`（支持断点续传，同时下载数有上限）。
- 用新的 `selfhost.sh` 重新运行一次即可升级。

**传输层 ard 4.0.0-pre.4、集成 FRD v5.4**（均未变）。
